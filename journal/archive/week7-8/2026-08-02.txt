2026-08-02

COLOR FILTER

Added a dropdown to the report view that filters by
All Games, Playing White, or Playing Black. Backend
stores three stat sets as JSON fields on the Report
model. Frontend switches between them instantly.

Extracted stat computation into a build_stats function
so it can be called three times with different game
lists. Updated the Report model, TypeScript interfaces,
and ReportIndex to use the new structure.

Added filteredGameCards so game cards also respect the
color filter. Fixed the dropdown being invisible in
dark mode.

EXPANDABLE CARDS

OpeningLineCard now supports expandable behavior via
optional props. When passed gameCards, isExpanded, and
onToggle, clicking a line card shows individual games
underneath. Without those props it renders as before.

Cleaned up OpeningFamilyCard — removed deeply nested
JSX. Each inner line is now a single OpeningLineCard
with expandable props. Same behavior, much less code.

Added child and childOfChild variant styling so nested
cards look visually distinct from parent cards.

BOARD ORIENTATION

Game view now shows the correct board perspective when
opened from a report. Player color is passed as a query
parameter (?color=white or ?color=black) in the URL.

Initially tried passing the player name and comparing
strings, but name mismatches broke it. Switched to
passing the color directly.

Threaded playerName through ReportView, OpeningFamilyCard,
OpeningLineCard, and GameCard so GameCard can determine
the color at link-creation time.

SORT DIRECTION

Added clickable arrow icons to sort buttons. Each
sortable section can now toggle between ascending and
descending order. handleSortChange resets direction to
sensible defaults when switching sort fields.

Fixed bar chart sort using allOpenings state instead of
its own barChart state.

GAME VIEW REDESIGN

Opponent name and elo above the board, player name and
elo below. Opening category, family, line, result, and
termination in the header.

Captured pieces display using react-icons chess icons.
A getCapturedPieces function parses the current FEN to
find missing pieces. They render inline next to each
player's name.

FRONTEND FEN MATCHING

Combined the five backend ECO JSON files into a single
frontend/public/data/eco.json. GameView fetches it once
on mount and checks each FEN position against it during
move replay. The current opening match updates in
real-time as the user steps through moves.

Added opening_category to the Game TypeScript interface.

BUG FIXES

Fixed weak lines pagination counting all lines instead
of only lines with win_rate < 50, causing blank pages.

Fixed GameView loading scrolled past the navbar.
