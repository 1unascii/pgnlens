STOCKFISH ON-DEMAND ANALYSIS

Implemented three-pass Stockfish analysis that runs
when a user opens a game:
- Pass 1: depth 8 (synchronous, ~5-8 seconds)
- Pass 2: depth 15 (synchronous, ~15-30 seconds)
  Currently commented out for testing
- Pass 3: 1.5M nodes (background thread, ~1-3 min)

Backend saves after each move so the frontend can
poll for partial results. Engine stays alive across
positions for speed. analyze_all_moves replaces the
old analyze_next_move (one move at a time).

Added analysis_complete boolean field to Game model
so the frontend poll knows exactly when to stop.
